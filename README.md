# The Meghan Compiler
Hello my name is Kenneth Looney and I am about to enter the journey in writing my very own compiler called *Meghan*. It is also going to be referred as the **meg** compiler. What makes this project special is it is dedicated to my niece who also inspired me into learning low level programming.

## You ask why another compiler project?
Well for the fun of it while learning what it takes! I also want to see how far I can go with it.

## Why now?
I have always wanted to understand meaning of *code* at the machine level.

## What to expect!
At the begining it is not going to be much. It's going to start out as just a *transpiler*. It's just going to *transpile* into C language code:
```meg
[meg source] -> [C code] -> [machine code]
```
## What Meghan aims to become
Meghan (meg) aims to become a compiler that uses it's own implemented backends such as:
- Freestanding environments
- Hosted environments such as:
    - Windows
    - Linux

I will have a lot to learn before this. This is why first its going to be a *transpiler*.

## Licesning
The compiler is going to be licensed under the Apache 2 license so after I get the initial version rolled out I will be releasing it to the public to also have the chance to contribute to it.
